# LIRY 烟花天幕

基于 Lit、TypeScript、Three.js 的单画布烟花应用。支持 WebGPU、WebGL 2、动态天幕和自适应控制面板。

## 开发与验证

```sh
pnpm install
pnpm dev
pnpm build
pnpm lint
pnpm test
pnpm test:browser
```

浏览器测试使用本机安装的 Chrome。手机、平板访问开发服务时，可运行 `pnpm dev --host 0.0.0.0`，使用同一局域网内电脑的地址打开。WebGPU 需要安全上下文；通过局域网 HTTP 访问时通常使用 WebGL 2，要测试移动设备上的 WebGPU 应部署到 HTTPS。

## 使用方式

- 手动模式：点击发射按钮或按空格，在 1 秒内发射一批；动画可继续升空、爆炸和消散。
- 自动模式：每一批重新随机选择数量和发射间隔。约 30% 围绕当前重点点燃放，其他烟花覆盖整片天幕；三个重点点轮换，每九批更新。
- 点击天幕：在点击处附近燃放，数量和范围独立随机；边缘点击只采样可见区域。
- 参数的最小值与最大值相同即为固定值。每批数量为 1–2000 朵，点击数量为 1–200 朵，自动间隔为 0.33–50 秒，点击半径为 7–1800 CSS 像素。
- 15 种具体烟花形态，以及随机形态；12 组配色可以多选，至少保留一组。
- 全屏仅包含天幕。暂停、清空、设置和文字均在天幕外，退出全屏可使用浏览器手势或 Esc。

极高密度燃放会减少每朵火花数、拖尾采样并调整渲染分辨率，以保留发射朵数。达到整体并发上限时会暂停新增自动批次，手动触发会显示繁忙提示；已经发射的烟花继续播放。

## HDR 与兼容性

自动模式优先 WebGPU，失败时回退到 WebGL 2；也可在设置中明确选择渲染引擎。明确选择 WebGPU 时不会静默切到 WebGL。

支持浮点缓冲的设备使用半浮点场景与 Bloom。HDR 输出按浏览器报告的屏幕能力启用半浮点画布及扩展 sRGB；SDR 使用色调映射。浮点渲染不可用时使用基础光效。HDR 的物理显示效果还受浏览器、操作系统、显示器及其设置影响，需要 HDR 真机确认。

## 代码结构

- `src/constant.ts`：默认值、参数上下限、配色、形态配置、粒子预算、采样权重、响应式断点与交互阈值。
- `src/components/`：天幕、工具栏、发射操作区、参数面板、标量滑块和范围输入组件。
- `src/fireworks/`：渲染引擎、发射调度、粒子池、15 种形态、天幕动画与空间采样。
- `src/ui/`：图标、共享样式和应用布局。
- `tests/`：调度、分布、参数、形态、ESLint 约束和浏览器交互测试。

所有私有成员使用 `#` 语法；所有控制语句必须加大括号。这两项由 ESLint 检查。格式化仍使用项目现有 Prettier 配置。
